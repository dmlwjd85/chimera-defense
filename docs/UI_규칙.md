# UI 규칙 (2026-11-26)

모든 화면의 버튼·글 상자·말풍선은 `src/scenes/theme.js`(색·선·모양)와 `src/scenes/ui.js`(부품)만 써서 그린다. 화면 코드에서 사각형·둥근 상자를 직접 그리지 않는다.

## 느낌
- 킹덤 러쉬처럼 **두꺼운 먹색 외곽선 + 밝고 따뜻한 손그림 색**. 오프닝 시안(나무·양피지·금빛 제목)과 맞춘다.
- 흐린 그림자·유리 광택·네온 같은 'AI 티' 효과는 쓰지 않는다. 그림자는 **번지지 않는 진한 그림자**를 아래로 4px만.

## 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 먹선 | `#291a1f` | 모든 외곽선, 글자 테두리 |
| 나무판 | 테두리 `#4a3222`, 안쪽 면 `#6b4a33` | 패널(글 상자) 바탕 |
| 나무판 안쪽 빛선 | `#a8794f` | 패널 안쪽 테두리 2px |
| 양피지 | `#f6e7c4` → `#ead29f` | 말풍선(툴팁), 확인 창 본문 |
| 양피지 글자 | `#3b2618` | 양피지 위 글자 |
| 금빛 | `#ffd45a` | 제목, 강조 숫자 |
| 버튼 종류 | 나무 `#a8703f` · 초록 `#5fae3c` · 파랑 `#3f86d1` · 보라 `#8a55c9` · 빨강 `#c8493a` · 금 `#e0a93a` · 잠김 `#857a6c` | 버튼 바탕 |

## 부품 (src/scenes/ui.js)
- `button` 버튼(`variant`로 종류), `panel` 나무 글 상자, `parchment` 양피지, `drawSlot` 칸(케이지·카드), `chip` 알약 칩, `showTip` 말풍선, `dimmer` 창 뒤 어둡게, `title` 제목, `modal`·`confirmBox`·`choiceBox`(widgets.js) 창.
- 예전 `fill` 색을 넘기면 가장 가까운 버튼 종류로 바뀐다(`variantOf`). 새 코드는 `variant`를 쓴다.

## 선·모양
- 외곽선 두께: 패널 4px, 버튼 3px(높이 32px 미만은 2px), 칩·말풍선 2px.
- 둥근 정도: 패널 12px, 버튼 높이의 1/4(최대 12px), 칩은 알약 모양.
- 버튼은 아래쪽에 **두께 4px의 어두운 턱**이 있어 눌리는 단추처럼 보인다.

## 버튼 상태
| 상태 | 모양 |
|---|---|
| 기본 | 위가 밝은 바탕 + 위쪽 가는 하이라이트 줄 + 아래 턱 |
| 올림(마우스) | 바탕 12% 밝게, 1px 위로 |
| 누름 | 턱이 사라지고 몸통·글자가 3px 아래로 |
| 못 누름 | 잠김 회색, 글자 흐리게(60%) |
- 화면마다 버튼 종류는 뜻으로 고른다: 출발·시작 = 초록, 이동·선택 = 파랑, 별자리·마법 = 보라, 나가기·초기화 = 빨강, 그 밖 = 나무.

## 글꼴과 크기 단계
- 글꼴: Noto Sans KR(없으면 맑은 고딕). 제목·버튼은 굵게.
- 크기 단계는 다섯 개만: **제목 40 · 소제목 24 · 큰 버튼 20 · 본문 16 · 작은 글 13**. 새로 쓰는 글자는 12px 이상(전투 조작판의 단축키·숫자 꼬리표 9~11px은 자리 때문에 아직 그대로).
- 버튼·제목 글자는 흰색/금빛에 먹선 테두리(크기의 1/5).

## 문구
- 버튼은 2~6글자. 한 줄 안내는 20자 안팎.
- 설명 문장 대신 **아이콘 + 숫자**(예: `⭐3 → 합류`, `💠12`).
- 말풍선은 이름 한 줄 + 효과 한 줄이 기본. 이야기 문장(설화)은 따옴표 한 줄로만.
- 수치·규칙은 지우지 않고 짧게 바꾼다. 바꾼 문구는 `docs/문구_전후.md`에 남긴다.
