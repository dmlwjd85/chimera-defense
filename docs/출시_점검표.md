# 키메라 디펜스 출시 점검표 (웹 + 플레이스토어)

2026-11-25 작성. Claude Code Game Studios(MIT)의 launch-checklist·플랫폼 요구사항을 우리 게임(Phaser 웹 게임 → PWA → 플레이스토어 TWA)에 맞게 줄였다.
표시: ✅ 됨 · 🟡 일부 · ⬜ 아직

## 1. 만들기·코드
- ✅ 자동 시험 통과(142개), 머지마다 CI에서 시험 → 빌드 → 배포
- ✅ 한 프레임 오류가 나도 게임이 멈추지 않음(`main.js`가 프레임 오류를 기록하고 넘어감)
- 🟡 튕김 기록: 전투 중 1초마다 상태 기록, `?debug=1`로 지난 기록·오류 보기. 서버로 모으지는 않음
- ⬜ 디버그·시험용 주소 옵션(`?k=`, `?dot=`, `?half=`, `?debug=`)을 출시판에서 정리할지 결정
- ⬜ 저장 데이터 깨짐 대비(불러오다 실패하면 새로 시작하되 백업 남기기)

## 2. 성능·기기
- 🟡 폰 메모리: 폰은 반 해상도 그림 묶음(그림 메모리 약 238MB → 약 80MB). 갤럭시에서 튕김 원인은 아직 확인 중
- ⬜ 목표 프레임(폰 30fps 이상) 실제 기기 측정: 갤럭시 S26 기본, 학교 태블릿
- ⬜ 오래 켜 두기 시험(15스테이지 연속, 메모리 늘어나는지)
- 🟡 앱 내려받기 크기: 묶음 34MB(PC)/20MB(폰). 처음 실행이 느리면 나눠 받기 검토
- ⬜ 화면 크기별 손가락 조작(폰 가로, 태블릿): 버튼·케이지 칸 누르기 쉬운지
- 🟡 다른 앱으로 갔다 오면 멈춤/이어하기(Phaser 기본 동작 확인 필요)

## 3. 내용
- ⬜ 임시 그림 없애기: 신화급·키메라 일부가 아직 예전 그림, 동물 동작 그림(걷기·공격) 없음
- ✅ 효과음 자체 합성(저작권 걱정 없음) / ⬜ 배경음악
- ⬜ 튜토리얼을 처음 하는 사람(학생)에게 시켜 보고 헤매는 곳 기록
- ⬜ 1~15스테이지 끝까지 깨지는지, 난이도(1스테이지 자동 플레이 클리어율 약 55~70%)
- ⬜ 글자 맞춤법·문체 검수(쉬운 말 규칙), 화면 밖으로 넘치는 글자

## 4. 법·스토어
- 🟡 에셋 출처 장부(`docs/에셋_출처.md`): 「확인 필요」 항목 정리
- ⬜ 크레딧 화면(Phaser MIT, pixelfx MIT, Sprite Fusion MIT)
- ⬜ 개인정보 처리방침 페이지(수집 없음이라도 스토어에 링크 필요)
- ⬜ 데이터 보안 양식(플레이스토어): 수집 데이터 없음, 기기 저장만
- ⬜ 연령 등급 설문, 교육용 분류 여부(학생 대상이면 가족 정책 확인)
- ⬜ TWA 포장(Bubblewrap 등), 앱 서명 키 보관, Digital Asset Links
- 🟡 스토어 그림: 아이콘 512 준비됨(`public/icons/store-icon-512.png`, 불투명). 기능 그래픽 1024×500, 스크린샷 가로 4장 이상은 아직

## 5. 사람에게 보여 주기 (영상 정리에서)
- 만든 사람이 좋다고 끝내지 않는다: 처음 보는 사람이 어디서 헤매는지, 무엇을 좋아하는지, 다시 하려는지 본다.
- 의견을 들으면 바로 바꾸기 전에 무엇이 불편했고 무엇을 기대했는지부터 묻는다.
- 기능을 더 붙이기 전에 지금 있는 것을 이해할 수 있게 다듬는다.
