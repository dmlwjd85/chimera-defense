# 적 원화 방향과 전투 방향 표

- 자동 생성: `node tools/gen_enemy_face_table.mjs` (기준 데이터는 `src/logic/enemyFace.js`의 원화 방향 표)
- 원화 방향 = 원본 그림을 크게 키워 본 결과(근거 한 줄 포함). 정면은 좌우가 비슷해 확실히 왼쪽으로 보이지 않으므로 오른쪽 그림과 똑같이 뒤집어 늘 왼쪽 모양으로 맞춘다.
- ❌ = 고치기 전에 교전 화면에서 왼쪽이 아니던 것. (홀림 나비·독무당벌레 떼는 이 PR의 앞 커밋에서 이미 고쳐서 "왼쪽"으로 적었다. 그 앞의 main에서는 오른쪽이었다.)
