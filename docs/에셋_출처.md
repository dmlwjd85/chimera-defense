## 효과음 (2026-11-26, 후보 2 — 13가지 역할)

`src/scenes/sfx.js`의 `sfx('이름')` 호출은 그대로이고, 아래 13가지 역할만 소리 파일로 재생한다. 파일이 없거나 불러오지 못하면 예전 합성음(WebAudio)이 난다. 나머지 효과음은 계속 합성음이다. 골라 자르고 소리 크기를 맞춘 과정은 `sound_drafts/`(작업 폴더, 저장소 밖)의 `출처장부.md`에 있다.

**파일 위치와 라이선스 조건이 둘로 갈린다.**

- **Kenney (CC0)** — `public/assets/sfx/*.ogg|mp3`. 저장소에 올린다. 상업 이용 가능, 출처 표시 필수 아님.
- **Sonniss GDC 2026 번들** — `public/assets/sfx/sonniss/*.ogg|mp3`. **저장소에 올리지 않는다**(`.gitignore`). 라이선스(버전 2.0, https://sonniss.com/gdc-bundle-license/)는 완성된 게임 안에 넣어 파는 것은 허용하지만, **효과음 파일 자체를 다른 사람에게 다시 나눠 주거나 그대로 파는 것, AI 학습에 쓰는 것은 금지**한다. 이 저장소는 공개라서 올리면 다시 나눠 주는 것이 된다. 앱(스팀 빌드)을 만들 때 그 폴더에 파일을 복사해 넣고 빌드한다(없으면 합성음으로 나온다). 원본 라이선스 문서(`License - GDC Game Audio.pdf`)는 작업 폴더 `sound_drafts/src/sonniss/`에 보관.

## 원칙 (영상 「AI로 게임 만들기, 시작은 쉬운데 그다음은?」 정리에서)
- 그림을 쓰기 전에 어디서 왔는지 먼저 적는다(이 장부에 한 줄).
- 「무료로 받을 수 있다」와 「팔 게임에 써도 된다」를 구분한다. 수정 가능 여부, 출처 표시 의무를 본다.
- 이름이 알려진 캐릭터·작품을 닮게 나온 그림은 버린다(작업기록 11: 박쥐 재생성).

## 쓰지 않기로 한 것
- Sunny Land(CC0): 화풍이 달라 안 씀.
- Sprite Forge(MIT): 지금은 도구만 참고. 동작 그림을 만들 때 `pixel_motion.py`(영상 → 우리 칸·팔레트) 사용 검토.
