# 보스 승률 조정 기록(자동 갱신)

목표(선생님 확정 "중간"): 노멀 맞춘 덱 85% 이상 · 노멀 안 맞춘 덱 50~65% · 하드 맞춘 덱 60% 안팎 이상(표에선 58% 이상이면 통과) · 하드 안 맞춘 덱 30% 이하.
도구: `tools/boss-tune.mjs` — 보스 직전까지 자동 봇으로 키운 상태를 칸마다 24판 찍어 두고 보스전만 설정별로 다시 돌림(12교전 기준). 숫자 = 보스 첫 도전 승률(%). 24판이라 한 칸 오차는 ±10%쯤.
`tools/boss-diag.mjs` — 진 판이 왜 졌는지(보스 남은 체력·시간·살아남은 동물) 한 판씩 보기.

## 2026-11-28 새로 찾은 버그(3회차까지의 표는 이 버그가 있던 상태)

- **진짜 보스가 미니보스로 잘못 잡힘**: 보스마다 '맛보기 기술 이름(taste)'이 있는데, 코드는 "taste가 있으면 미니보스"로 갈랐음. 그래서 모든 보스가 미니보스 취급 → 단계 전환(70%·40%) 없음, 광포화 없음, 호위 적 체력 절반 안 됨, **80초가 지나면 '체력 비율'로 승패를 갈라서 보스를 못 잡아도 이김**. 튼튼한 동물만 넣은 '안 맞춘 덱'이 더 잘 깨던 이유(박쥐왕·숲의 그림자·까막 사제).
- **보스를 잡고도 졸개에게 짐**: 박쥐왕 맞춘 덱은 보스를 다 잡고(보스 체력 0) 남은 박쥐 떼에게 전멸해 패배로 기록됐음. → 보스가 쓰러지면 보스가 부른 졸개도 흩어지게 고침.
- 두 가지를 고친 뒤 4회차부터 다시 맞춤.
