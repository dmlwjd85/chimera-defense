# 열린 성문 배경 만들기 (2026-11-25)
제미나이 이미지 한도 때문에 배경의 닫힌 나무문을 코드로 열린 문(어두운 통로·안쪽으로 열린 문짝·횃불빛)으로 칠함.
1. `python3 door.py <배경.jpg> m.png x0 y0 x1 y1 [채도]` — 나무문 영역 찾기
2. `python3 shape.py m.png cx ys rx ry 아래왼쪽y 아래오른쪽y 오른쪽끝x` — 아치 모양으로 다듬기(필요할 때)
3. `python3 open.py <배경.jpg> m.png <결과.jpg> 오른쪽끝x`
값: forest-1 `0 450 420 1100` / x 124, forest-2 `0 400 76 845 0.42` + shape `30 470 50 65 845 760 74` / x 76, forest-3 `0 410 146 880 0.42` + shape `72 500 75 80 860 790 144` / x 146
