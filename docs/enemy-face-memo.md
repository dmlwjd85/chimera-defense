# 적 방향 검수 메모 (PR #86, wt-face2) — 2026-11-28

## 1. 두 적의 정체 (데이터 확인)
- **도둑여우** → 데이터에 이 이름은 없음. 여우 모양 적은 `fast` = **복면 여우 자객** 하나뿐(검은 복면 + 단검). 가장 유력.
  - 참고: 우리 편 조합 중 `cheese_thief` = "치즈 도둑"(여우+까마귀, 우리 편)이 있으나 적이 아님. 적 쪽 "도둑"은 복면 여우 자객뿐.
  - 시트: `en_fast` (하드·하드코어 그림 없음, 등급 색 변형만 있음).
- **파란 나비** → `flying` = **홀림 나비** (파란 몸). 시트 `en_flying`(하드 그림 없음).
  - 색 바꿈 변형: 정예 등급이 붙으면 외곽선 색만 바꾼 시트(`rankDot`, 이름 앞에 "푸른/붉은/검은")가 쓰임. 푸른 등급 = "푸른 홀림 나비"가 사용자가 말한 "파란 나비"일 수도 있음. 방향은 같은 시트 틀이라 faceId는 `flying` 그대로.
  - 시트가 로드되지 않았을 때 쓰는 예비 그림(`enemy-flying.png` + `flipArt`)도 별도 경로라 같이 확인.

## 2. 진행 기록 (결과를 단계마다 아래에 추가)

### 단계 2 결과 (전투 화면 스크린샷, 걷기·공격·스킬·피격·죽음·등장)
- 복면 여우 자객(`fast`)·홀림 나비(`flying`) **움직이는 시트**: 모든 동작에서 왼쪽(뒤집기=예) ✔ — 푸른/붉은/검은 등급(색 바꿈 시트)도 같음 ✔.
- **원인 발견**: 시트(dot)가 아직 안 올라왔거나 못 올라온 때 쓰는 **예비 한 장 그림**(`enemy-<이름>.png`, flipArt)은 `setFacing(-1)`이 오히려 **오른쪽**이 됨. 시트 로딩 전·실패 때 여우·나비(그리고 모든 적)가 오른쪽을 봄 → 사용자가 본 "오른쪽 보고 싸움"의 유력한 원인.
- 고침: `enemyFaceRig(rig, id, back)` — 예비 그림이면 반대 부호. 등장·매 프레임·필살기 컷신·BattleScene 4곳에 적용.
- 고친 뒤 예비 그림 확인(시트를 일부러 빼고 교전): 홀림 나비·복면 여우 자객·서리 망령·떠도는 넋·보라 꼬마 도깨비 모두 등장·걷기·공격·스킬·피격·죽음에서 왼쪽 ✔ (고치기 전엔 나비 머리·여우 단검이 오른쪽).
