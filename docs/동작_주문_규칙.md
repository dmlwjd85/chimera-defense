# 동작·그림 주문 규칙

키메라 디펜스의 캐릭터 그림과 동작을 주문·검수할 때 쓰는 공통 규칙입니다. 숫자를 지어내지 않고, 산군 필살기 검수에서 실제로 쓴 기준만 적습니다.

**주문 틀:** [`tools/pixellab/request_template.json`](../tools/pixellab/request_template.json)

## 출처

- 개발자 김뽑희, [AI티 안나게 게임 캐릭터 만드는 방법](https://www.youtube.com/watch?v=U-M_cP3Nw1Q) (2026-11-09). 참고한 방법만 가져왔고, 영상에 나온 작업 시간·장수 같은 숫자는 우리 기준으로 쓰지 않습니다.
- 산군 필살기 검수 기록: `sangun_ult_v3/qa_v3.md`, `sangun_ult_v3/plan.md` (기준 방향 = 정면 south). 외곽선 색은 저장소 `tools/check_dot.py`, `src/rig/dotData.js`의 `OUTLINE`.

## 공통 금지

아래는 어떤 캐릭터·어떤 동작에도 쓰지 않습니다.

- 팔·다리만 잘라 붙이기 금지
- 팔·다리만 늘리거나 줄여 포즈를 만드는 것 금지
- 중간 그림을 합성해 사이 장을 만드는 것 금지
- 포즈가 바뀌면 **연결된 몸 전체를 같은 캐릭터·같은 설정으로 통째로 다시 생성**합니다.

## 산군에서 나온 거절 기록 (다음 동작에도 기본 적용)

비율 검수의 기준 방향은 **정면(south)** 입니다. 아래 숫자는 `qa_v3.md` / `plan.md`에 적힌 그대로입니다.

- 키: 정면 대비 **±4%** 이내면 합격, 벗어나면 불합격
- 머리 높이 비율(머리 높이 ÷ 키): 정면 비율 대비 **±5%** 이내
- 발밑선 y: 정면과 **±1px**
- 어깨 폭: 정측면(east/west)은 정면의 **70% 이상**, 대각선·뒷면은 정면의 **85% 이상**. 미달이면 불합격
- 머리 폭: 정면 대비 **±8%** 이내
- 옆모습 어깨 폭이 정면의 70% 미만이면 불합격 (산군 v3 회전에서 east/west가 55%라 실패한 항목)
- 팔에 머리가 가리면 불합격
- 외곽선 색은 **`#291a1f`** (`check_dot.py` / `DOT` 규격). 다른 색으로 남아 있으면 정리하거나 다시 뽑습니다
- 떨어진 점·외딴 점은 **0개**
- 필살기처럼 한 바퀴 돌며 끝나는 동작의 **마무리 자세는 정면(south)** 을 봅니다

참고(`qa_v3.md`): 64px 도트에서 머리 높이 1px는 약 5%라서, 머리 비율 기준은 1px만 달라도 불합격이 날 수 있습니다.

## 참고 그림 역할 표기

참고 그림을 여러 장 줄 때는 **장마다 역할 한 줄**을 적습니다. 역할을 나누지 않고 그냥 주면 그림체와 모양이 섞입니다.

| 역할 값 | 뜻 |
|---|---|
| `style` | 그림체만 참고 (유일한 그림체 기준) |
| `shape_pose` | 모양과 포즈만 참고 |
| `color_material_light_only` | 색·소재·빛만 참고. 얼굴·머리·옷 구조는 베끼지 않음 |

주문 틀의 `reference_images` 배열에 `{ "path": "...", "role": "style" }` 형식으로 적습니다.

## 실루엣 검사

비율 검사와 별도로, 스프라이트를 **검게 칠한 뒤** 실제 전장 크기(도트 1칸 = 화면 2×2px, `src/rig/dotData.js`의 `DOT_PX = 2`)로 놓고 다른 유닛과 나란히 봅니다. 이름을 가려도 누구인지 구별되면 합격, 실루엣이 비슷해 구별이 안 되면 불합격입니다.

도구: `tools/silhouette_check.py`

## 키메라는 섞인 동물 부위가 실루엣에서 읽히게

키메라·합성 결과는 귀여운 동물 한 마리처럼 동글동글하게만 보이지 않게 합니다. 어떤 동물·소재·부위가 섞였는지 **실루엣에서 먼저** 읽혀야 합니다.

## 실제 게임 화면 나란히 검수

시트에서만 예쁘다고 통과시키지 않습니다. **전장, 합성 칸, 선택 화면**의 실제 크기로 놓고 다른 유닛과 나란히 비교한 다음에 통과합니다. 날개·장식이 몸을 작아 보이게 하면 그 화면용으로 다시 맞춥니다.

## 전후 비교 필수 · 통과 원화는 국소 수정만

- 고친 그림은 반드시 이전 것과 **나란히** 놓고 좋아졌는지 봅니다.
- 한 번 통과한 원화는 전체를 다시 그리지 않고, 필요한 **한 곳만** 고칩니다.

## 색 톤·외곽선 통일

- 모든 유닛의 외곽선은 `#291a1f`로 맞춥니다.
- 같은 16색 팔레트를 쓰더라도, “같은 컬러감”은 색 코드를 전부 같게 하라는 뜻이 아니라 **밝기와 선명함의 톤**을 맞추라는 뜻입니다.
- 팔레트 불투명 색은 종마다 최대 16색입니다 (`src/rig/dotData.js`의 `MAX_COLORS`).

## 이펙트는 캐릭터 정체성에 맞게, 모았다가 한 번에

이펙트가 여러 갈래로 흩어져 어지러우면, 캐릭터 정체성에 맞게 **한곳으로 모은 뒤 한 번에** 터지거나 나가게 합니다. (산군 필살기: 올라가며 회오리가 몸을 감고, 정면 착지에서 충격파와 흙먼지가 한 번에 퍼짐.)

## 동작 주문서 양식

새 동작을 주문할 때 아래를 한 세트로 채웁니다. 빈칸은 지어내지 말고 선생님께 묻습니다.

```
캐릭터:
원화 1장 id / 경로:
참고 그림과 역할:
  - (경로) — 역할(style / shape_pose / color_material_light_only)
동작:
  - 이름:
    장수:
    장면별 시간(ms): [ ]
    표정 메모:
합격 기준:
  - 비율: 키 ±4%, 머리비율 ±5%, 발밑선 ±1px, 어깨 옆 70%/대각·뒷면 85%, 머리폭 ±8% (기준 정면 south)
  - 실루엣 검사, 전장·칸·선택 화면 나란히 비교, 전후 비교
  - 외곽선 #291a1f, 외딴 점 0, (해당하면) 마무리 자세 정면
  - 팔에 머리 가림 없음, 부분 합성·늘리기·잘라 붙이기 없음
```

주문 틀 JSON에서는 `motion_order.anchor_art_id`와 `motion_order.motions[]`(`name`, `frame_count`, `frame_ms`, `expression_notes`)에 같은 내용을 적습니다.

## 동물 동작(PixelLab animate-with-text-v3) — 2026-11-26 곰·독수리 시안에서 정한 것

- 주문서: [`tools/pixellab/motion_spec.py`](../tools/pixellab/motion_spec.py) (동작 문장·장 수·칸 크기를 여기서만 고침), 묶는 도구: `tools/build_pixellab_motions.py`
- 확정 원화를 첫 장으로 주고 몸 전체를 PixelLab이 다시 그림 → 잘라 붙이기·늘리기·사이 장 합성 없음
- 단계별 동작(기술 묶음과 같음): 아기 대기·걷기·기본1·맞기·쓰러짐 / 성장기 +기본2 / 성체 +속성 / 신화급 +필살기
- 반복 동작(대기·걷기)은 **첫 장 = 끝 장**(last_frame)으로 주문해야 이음매가 안 끊김
- 나는 새(독수리·까마귀)의 아기·성장기·성체는 서 있는 원화가 아니라 **날개 편 나는 자세**를 첫 장으로. 공격·맞기도 그 자세로 돌아오게 끝 장을 같게
- 첫 장은 반드시 **눈 뜬 장**(자동으로 고르면 눈 감은 장이 걸려 모든 동작이 눈을 감음 — 독수리 성장기에서 한 번 다시 뽑음)
- 투사체·빛·연기는 동작에 넣지 않고 코드가 그림. 원거리 투사체 그림은 `public/assets/fx/proj/<종>.png`(새는 깃털)
- 정리: 반투명 0, 외딴 점 0, 몸에서 떨어진 조각 지움, 색은 그 종 확정 원화 팔레트(16색)로만, 쓰러짐은 가장 낮게 누운 장에서 멈춤
- 검수: 단계×동작 표 GIF(`tools/pixellab/motion_board.py`), 전투 화면 GIF, `tests/dot.test.js`의 동작 시트 검사
- 폰 메모리: 동작 시트는 장마다 빈 곳을 잘라 묶고, 전투에 들어갈 때 덱에 든 종만 불러오고 끝나면 내림
- 대기 문장에 'breathing(숨 쉬기)'을 쓰면 머리 위에 김·물음표가 붙어 나옴 → 'standing still, eyes blink once, no steam'으로 씀(개구리·개미·메뚜기·수탉에서 다시 뽑음)
- 쓰러짐은 'legs give way, ends lying flat on its side, completely still'처럼 끝 자세를 분명히 씀(예전 문장은 선 채로 끝나는 일이 많았음). 그래도 낮게 눕지 않으면 코드가 살짝 가라앉힘
- 몸에서 떨어진 조각(가장 큰 덩어리의 25% 미만)은 지움. 몸에 붙은 김은 못 지우니 다시 뽑음
- 동시에 많이 주문하면 PixelLab이 429로 거절 → 4개 이하로, 거절되면 기다렸다 다시(anim.py)
- 동작표 GIF는 쓰러짐을 반복 재생하므로, 쓰러짐 검수는 마지막 장을 따로 열어 봄
