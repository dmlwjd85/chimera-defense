## 효과음 (2026-11-27, 전투 소리는 합성음으로 되돌림)

`src/scenes/sfx.js`의 `sfx('이름')` 호출은 그대로이다. 파일이 없거나 불러오지 못하면 합성음(WebAudio)이 난다.

2026-11-27 선생님 지시로, **전투에서 자주 나는 7가지 역할은 PR #62 이전의 합성음으로 되돌렸다**(hit·slam·shoot·kill·magic·shield·heal). `sfx('skill')`은 예전에 정의가 없어서 아무 소리도 안 났는데, 지금은 예전 magic 합성음으로 연결한다. 이 7가지에는 높낮이 흔들기와 적 타격 -4dB을 적용하지 않는다. 같은 소리 0.3초 안에 3번 제한은 빠른 타격을 줄여서 예전과 다르게 들리므로, 이 7가지는 예전처럼 이름별 최소 간격(`MIN_GAP`)만 쓴다.

**그대로 둔 파일 소리(6가지, Kenney CC0 1.0).** 상업 이용 가능, 출처 표시 필수 아님(공식 FAQ https://kenney.nl/support). 팩 라이선스 원문: `public/assets/sfx/LICENSE-kenney-*.txt`.

파일은 모두 모노 48kHz로 잘라 ogg(Vorbis 품질 3)와 mp3(96kbps)로 저장했다(ogg를 못 읽는 기기에서 mp3로 대신 재생).

**믹스 규칙**(`sfx.js`): 파일 소리는 같은 이름 0.3초 안에 3번까지만 시작, 재생 속도(높낮이) ±8% 흔들기. 전투 합성음 7가지는 예전 최소 간격만 적용.

## 원칙 (영상 「AI로 게임 만들기, 시작은 쉬운데 그다음은?」 정리에서)
- 그림을 쓰기 전에 어디서 왔는지 먼저 적는다(이 장부에 한 줄).
- 「무료로 받을 수 있다」와 「팔 게임에 써도 된다」를 구분한다. 수정 가능 여부, 출처 표시 의무를 본다.
- 이름이 알려진 캐릭터·작품을 닮게 나온 그림은 버린다(작업기록 11: 박쥐 재생성).
